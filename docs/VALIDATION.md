## 验证边界

- 内嵌浏览器安全策略只允许 HTTP(S)，拒绝 file:// 导航。因此没有通过该工具实测双击 index.html 的文件协议模式，未绕过限制。该模式采用相对静态资源和普通脚本标签，不依赖 fetch 或模块加载；缓存离线运行已实测。
- 尚未做真实 x86 CPU 或 GNU 工具链的完整差分测试，也没有对所有指令编码组合做穷举。
- 不承诺运行任意 x86 程序。反汇编文本与机器码一致性不在当前验证范围，支持范围详见 README。
