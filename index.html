INITIAL STATE
从什么状态开始？
这些设置作用于模拟内存。修改后将重新载入程序。
进程参数、环境和虚拟文件
argv 包含程序名；程序输入框作为 stdin。虚拟文件仅供 fopen 读取，绝不访问真实系统文件。PID 和 rand 算法为可重复的教学值。
例：argv 为 ["program","input.txt"]，文件为 {"input.txt":"41 42 43"}。
自定义寄存器和内存映射
寄存器值用字符串表示。自定义区域不得与栈、代码或数据重叠。
示例：[{"address":"0x3ff000","size":4096,"hex":"41 42 00"}]

  
FIELD GUIDE / v0.2.1
关于这间汇编实验室
所有模拟在浏览器中完成。下载完整项目后，直接打开 index.html 即可离线使用；代码不会发送到服务器。
从这里开始
  1. 选择左侧示例，点击「单步」。高亮行表示下一条指令。
  2. 观察寄存器的高亮、内存字节和「这一步发生了什么」。
  3. 切换「编辑」修改代码，然后「载入程序」。F10 单步，F8 回退，F9 运行 / 暂停。
  4. 越界实验中修改输入长度，再重新载入。暂停提示后可继续观察后果。
  5. 「保存实验」导出代码、初始设置、输入和断点；导入后从初始状态运行。
精确模拟与教学约定
使用 64 位整数、逐字节小端内存与真实指令编码长度。源代码采用确定的编码策略（例如长跳转），不保证与 GNU as 生成的地址完全相同。复现已有地址时请导入带机器码的反汇编。
反汇编按指令文本执行，机器码用于地址、长度与显示，本版不重新解码校验。模拟区域未写入的字节以 0 初始化；这不代表真实进程中的栈初值。
函数模式默认预置教学返回地址；ELF 进程从真实入口启动，初始栈放置 argc、argv、envp 和教学辅助向量。栈帧与保存的 RBP 标签依据常见序言推断；实际读写始终以指令为准。
缓冲区标注
在缓冲区地址已确定后、使用前添加：
# @buffer input, -16(%rbp), 16
leaq -16(%rbp), %rdi
标注不消耗指令。软件跟踪从该区域取得的指针，以及简单的复制与加减；不能替代完整的内存安全分析。缓冲区本身的边界需要示例或用户标注。
从 _start 运行完整程序
导入完整反汇编后，点击「装载原始 ELF」选择同一个程序的可执行文件（可能没有扩展名）。逐条核对机器码字节，装载常量与全局数据，自动从 ELF 入口建立进程。库函数模型各作为一步，程序自身的启动代码与函数体仍逐条执行。只提供代码截段、缺少原文件或依赖尚未实现的指令 / 库函数时，无法保证完整运行。
输入区供标准输入读取。若程序自己把 ASCII 十六进制文本转换为字节，应选择 UTF-8 并输入 41 42 43，而非选择 HEX 后提前解码。参数及虚拟文件可在「初始状态」设置。保存实验会把配套 ELF 数据一并保存，之后可离线导入。
当前指令范围
支持常用整数传送、算术、比较、逻辑、移位、乘除、条件跳转、call / ret / leave 和基本数据指示。支持 8/16/32/64 位寄存器别名。未支持的指令会明确报错。
getchar、putchar、puts、printf、rand、exit 为可回退的教学模型，函数体不执行真实系统调用。printf 支持 %d、%u、%x、%s、%c、%% 与最多五个寄存器参数；不模拟完整 C 库。rand 使用固定种子的模型算法。
支持固定地址 x86-64 ELF 装载、必要的 GOT 重定位、libc 启动 / 清理、标准输入与虚拟文件、memset、mmap / munmap 及向下增长栈的教学模型。尚未实现完整 Linux、PIE、任意共享库、SIMD、浮点、直接系统调用、栈保护 / ASLR / NX、自修改代码或任意机器码执行。未知跳转目标会停止并显示地址。
回退保留最近 2,000 步，包括输入位置、映射和运行环境。「运行」直接执行到断点、结束、异常或覆盖告警，停止时才更新可视化；可随时点击「暂停」。设置或取消断点不改变当前滚动位置。需要逐条观察时使用「单步」。额外架构将通过独立的解析与执行适配器加入。
