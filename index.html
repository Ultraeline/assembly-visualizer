从这里开始
  1. 选择左侧示例，点击「单步」。高亮行表示下一条指令。
  2. 观察寄存器的高亮、内存字节和「这一步发生了什么」。
  3. 切换「编辑」修改代码，然后「载入程序」。F10 单步，F8 回退，F9 运行 / 暂停。
  4. 越界实验中修改输入长度，再重新载入。首次告警暂停后，点击「继续运行」到断点或结束；也可单步观察。回退或重置后重新启用告警暂停。
  5. 「保存实验」导出代码、初始设置、输入、断点和变量绑定；导入后从初始状态运行。
精确模拟与教学约定
使用 64 位整数、逐字节小端内存与真实指令编码长度。源代码采用确定的编码策略（例如长跳转），不保证与 GNU as 生成的地址完全相同。复现已有地址时请导入带机器码的反汇编。
原反汇编按指令文本执行，不校验文本与机器码的语义一致性。跳转到指令表外或已改写的内存时，按当前字节尝试解码常用整数指令；动态指令会显示在列表中，可单步、回退和设置断点。模拟区域未写入的字节以 0 初始化；这不代表真实进程中的栈初值。
函数模式默认预置教学返回地址；ELF 进程从真实入口启动，初始栈放置 argc、argv、envp 和教学辅助向量。栈帧与保存的 RBP 标签依据常见序言推断；实际读写始终以指令为准。
栈里的函数入口地址
「栈与内存」按每行完整的 8 字节小端值识别已知函数入口，在「含义 / 数值」栏显示函数名和实际地址，保留返回地址、保存的 RBP、缓冲区等原有标注。覆盖或回退后自动更新；不完整或不可读的字节不识别。只匹配入口本身，不把函数内部偏移当作入口。
函数名来自反汇编的函数标题、ELF 函数符号、源码的 .type name, @function 声明、main / _start、直接 call 的目标以及已知库函数。仅有普通源码标签时无法确认函数身份，可添加 .type 声明。地址标注不表示程序一定会调用它。
动态栈空间
执行 sub %rax, %rsp 等明确调整栈顶的分配指令后，「动态栈空间」自动记录新 RSP 到原 RSP 之间的地址和字节数，地址固定。选择对应空间即可分页查看全部内容、定位到普通内存视图，或把当前页添加为命名变量。支持常量 SUB / ADD、以 RSP 为基址的 LEA 及常见 AND 对齐；PUSH / CALL 不作为分配，任意 MOV 换栈不自动推测分配。
每次分配单独编号，递归和循环不会合并。RSP 上移或所属调用返回时推断部分 / 完全释放，回退同步恢复。每块保留最近 100 次内容变化，每次列出前 16 个变化字节，最多保留最近 64 块空间。已释放空间显示当前内存，可能被复用，不继续记录内容。未映射处不会因观察而自动映射。这里只推断栈空间，不自动认定其中某个缓冲区的真实边界。
变量监视
点击「添加变量」，给寄存器（例如 eax）或内存（例如 -8(%rbp)、0x600000、数据标签）命名。选择整数、十六进制、字节或文本；点击变量名查看变化步骤、指令和前后值。运行时逐条记录，停止后刷新；回退会撤销未来记录。每个变量保留最近 200 次变化，重置后清空。
跟随表达式会随基址寄存器改变位置；在栈帧已建立后选择「固定到当前地址」，可以持续观察那块内存。固定地址在函数返回后仍可读，不表示变量还在作用域内。执行 MOV、扩展 MOV、CLTQ / CWTL、XCHG、PUSH / POP 时，变量名会随实际数据复制到寄存器；变量卡片列出关联寄存器及其真实值。缓冲区片段以 buf[起点:终点] 标注，终点不包含在内。原位置变化而寄存器保留不同值时显示「旧副本」。支持的运算会生成表达式；覆盖或不支持的运算会取消受影响的关联，部分覆盖保守地取消整个重叠关联；回退同步恢复。LEA 计算的地址不标成变量内容。普通扩展副本的部分读取及未列出的指令不推断来源。每个变量最多保留最近 256 个副本位置（含内存中转），不自动识别源代码变量或作用域。配置随实验和草稿保存，变化记录不导出。
变量表达式与指针解引用
对保存 y 的寄存器 RBX 执行 add %rax, %rbx，且 RAX 来自 x 时，y 的卡片会直接显示「RBX 中加了 x」和真实前后值，例如 5 → 8，并标注步骤。该说明跟随被修改的值，x 不会被误标为发生了加法。继续运算、复制后运算和回退会同步记录；卡片保留最近一次说明，下方可查看完整变化记录。监视位置的当前值仍反映原绑定位置。
若 RAX 来自 x、RBX 来自 y，执行 addq %rax, %rbx 后显示 RBX ← y + x；sub 的顺序是 y − x。支持 ADD / SUB、INC / DEC、NEG / NOT、AND / OR / XOR、二或三操作数 IMUL，保留括号和实际位宽。同一寄存器 XOR / SUB 清零按常量处理；移位、隐式双宽乘除法及库函数内部暂不推导。
若 RAX 保存指针变量 x，mov (%rax), %rbx 显示 RBX ← *x；带偏移显示 *(x + 8)，还可形成 y + *x。变量卡片列出实际地址、读取位宽和当时取出的值。表达式使用指令执行时的快照；原变量或目标内存后来改变，不会重新计算寄存器值。LEA 不读取内存，不标成解引用。
表达式随复制、内存中转、PUSH / POP、XCHG 和回退更新；结果按目标位宽截断，扩展和取位会明确标注。每个表达式最多 63 个节点、10 层，超过时折叠为「阶段值@步骤」，保留实际值和变量关联。删除或重新绑定变量会清除依赖它的表达式。
缓冲区标注
在缓冲区地址已确定后、使用前添加：
# @buffer input, -16(%rbp), 16
leaq -16(%rbp), %rdi
标注不消耗指令。软件跟踪从该区域取得的指针，以及简单的复制与加减；不能替代完整的内存安全分析。缓冲区本身的边界需要示例或用户标注。
从 _start 运行完整程序
导入完整反汇编后，点击「装载原始 ELF」选择同一个程序的可执行文件（可能没有扩展名）。逐条核对机器码字节，装载常量与全局数据，自动从 ELF 入口建立进程。库函数模型各作为一步，程序自身的启动代码与函数体仍逐条执行。只提供代码截段、缺少原文件或依赖尚未实现的指令 / 库函数时，无法保证完整运行。
输入区供标准输入读取。若程序自己把 ASCII 十六进制文本转换为字节，应选择 UTF-8 并输入 41 42 43，而非选择 HEX 后提前解码。参数及虚拟文件可在「初始状态」设置。保存实验会把配套 ELF 数据一并保存，之后可离线导入。
当前指令范围
支持常用整数传送、算术、比较、逻辑、移位、乘除、条件跳转、call / ret / leave 和基本数据指示。支持 8/16/32/64 位寄存器别名。未支持的指令会明确报错。
getchar、putchar、puts、printf、rand、exit 为可回退的教学模型，函数体不执行真实系统调用。printf 支持 %d、%u、%x、%s、%c、%p、%% 与最多五个寄存器参数；不模拟完整 C 库。rand 使用固定种子的模型算法。
支持固定地址 x86-64 ELF 装载、必要的 GOT 重定位、libc 启动 / 清理、标准输入与虚拟文件、memset、mmap / munmap 及向下增长栈的教学模型。尚未实现完整 Linux、PIE、任意共享库、SIMD、浮点、直接系统调用、栈保护 / ASLR / NX 或任意机器码执行。动态解码仅覆盖 MOV / LEA、基本算术逻辑、PUSH / POP、近跳转 / 调用 / 返回和 NOP 等常用整数编码；不支持的编码或不可读取指会停止并显示地址。
回退保留最近 2,000 步，包括输入位置、映射和运行环境。「运行」直接执行到断点、结束、异常或首次覆盖告警。点击「继续运行」后保留告警但不再反复暂停；回退、重置或重新载入会重新启用告警暂停。停止时才更新可视化；可随时点击「暂停」。设置或取消断点不改变当前滚动位置。需要逐条观察时使用「单步」。额外架构将通过独立的解析与执行适配器加入。
