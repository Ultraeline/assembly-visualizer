# 可视化汇编运行

[直接在线使用](https://ultraeline.github.io/assembly-visualizer/) · 无需下载或安装。

在浏览器里逐步观察 x86-64 AT&T 汇编：寄存器的值从哪里来、栈顶如何移动、函数如何返回、越界写入如何覆盖邻近内存。

**v0.5 是可运行的教学模拟器，不是完整的 x86 CPU、操作系统或二进制调试器。** 完全在浏览器本地执行，无第三方运行时依赖，无 CDN、账号和云端代码执行。采用 MIT 许可证。

v0.7.1 在目标变量的卡片和变化记录中直接说明寄存器运算，例如在 y 下显示「RBX 中加了 x：5 → 8」。说明跟随被修改的值，来源变量不会误标为被修改；支持回退及连续运算。

v0.7.0 变量监视新增运算表达式与指针解引用：显示 `y + x`、`y − x`、`*x`、`*(x + 8)`、`y + *x` 等来源表达式，保留实际数值、读取地址、位宽和取用时的变量值；复制、回退及变化记录同步更新。

v0.6.0 变量监视新增寄存器关联：跟随实际数据复制，在寄存器旁显示变量名，在变量卡片显示副本位置、实际值及变化记录。支持缓冲区片段、旧副本、覆盖清除与回退。

v0.5.1 在栈与内存的「含义 / 数值」栏标注已知函数入口：完整 8 字节小端值匹配入口时显示函数名及实际地址，覆盖和回退时同步更新，保留原有栈槽标注。

v0.5.0 新增动态栈空间自动跟踪：记录运行时分配的地址、大小、内容变化与释放状态，支持分页、回退，以及将当前页添加为命名变量。

v0.4.0 新增手动命名的变量监视：绑定寄存器、栈位置或固定内存，显示当前值和逐指令变化记录，支持回退及实验保存。连续运行仍在停止时才刷新界面。打开上方在线链接，进入「变量监视 → 添加变量」即可使用。

v0.3.1 采用白色为主、蓝色为辅的界面。侧栏、按钮、指令高亮、寄存器与栈内存使用统一配色；越界和异常保留橙红色提示。

v0.3.0 修复越界后反复暂停，增加内存机器码的有限动态解码与指令显示，并补齐 printf 的 %p 地址输出。已有实验文件与浏览器草稿仍可继续使用。

## 直接使用 / 离线使用

1. 下载或复制整个项目目录。
2. 用现代 Edge、Chrome 或 Firefox 打开 `index.html`；Windows 也可双击 `start.cmd`。
3. 选择「看见一次函数调用」，点击「单步」。

无需安装 Node.js，也无需联网或租服务器。需要把 HTML、JS、CSS 等文件放在一起，不能只复制 HTML。

如果浏览器限制本地文件，也可安装 Node.js 后运行 `npm start`，访问终端显示的本机地址。它只监听 `127.0.0.1`。网站通过 HTTP(S) 使用时，会尝试缓存静态资源；最可靠的离线方式仍是保留完整本地文件包。

## 主要功能

- 两种文本入口：AT&T 汇编源代码、带地址和机器码的 objdump 风格反汇编。
- 单步、连续运行、暂停、断点、重置和最近 2,000 步回退。
- 16 个通用寄存器、RIP、ZF/SF/CF/OF/PF/AF，以及部分寄存器视图。
- 逐字节小端内存，RSP/RBP 标记、返回地址、调用栈与常见栈帧推断。
- 每步读写说明、寄存器高亮、内存改动和越界提示。
- 手动命名变量，显示当前值和最近 200 次变化；支持寄存器、栈地址、数据标签，以及整数、十六进制、字节和文本。
- 用户可配置入口、初始寄存器、栈地址、额外内存区域与输入。
- 实验文件导入 / 导出、浏览器本地草稿保存。
- 七个示例：函数调用、递归、部分寄存器、缓冲区越界、RIP 相对寻址、反汇编、动态栈空间。

## 从 _start 运行完整反汇编

1. 导入带机器码的完整反汇编文本。
2. 点击「装载原始 ELF」，选择生成这份反汇编的原始 x86-64 可执行文件（可以没有扩展名）。软件核对指令字节，读取 `.rodata`、`.data`、BSS、初始化数组与动态符号连接；文件不会上传到服务器。
3. 自动模式下从 ELF 入口建立 Linux 教学进程：初始栈含 `argc / argv / envp / auxv`，然后执行 `_start → __libc_start_main → 初始化函数 → main → 清理函数 → 退出`。库函数模型作为单步事件显示，已导入的程序代码仍逐条执行。
4. 侧栏输入作为 stdin；在「初始状态」设置 argv、envp、虚拟文件和教学 PID。若程序需要 **ASCII 十六进制文本**（例如自己调用 digit2hex），请选 UTF-8 输入 `41 42 43`；HEX 模式会直接提供字节 `41 42 43`，二者不同。
5. 在感兴趣的函数入口设置断点，点击「运行」直接到达断点，再用单步查看。保存实验会包含配套 ELF 数据，可重新导入并离线运行。

支持固定地址 ET_EXEC、小端 ELF64、x86-64；暂不支持 PIE、缺失节表的 ELF、任意共享库和所有动态重定位。原文件与反汇编不匹配时拒绝装载。字节比对不等于重新反汇编，指令语义仍取自文本。只有反汇编截段时，不能从中恢复缺失数据或完整程序。

## 操作

| 操作 | 说明 |
| --- | --- |
| 载入程序 | 从代码和当前设置生成新的初始状态 |
| F10 / 单步 | 执行当前高亮的下一条指令 |
| F8 / 回退 | 撤回一步，包括内存、输入位置、输出、标志位和调用跟踪 |
| F9 / 运行 | 直接运行到断点或结束；再次点击暂停，停止时刷新视图 |
| 指令行左侧圆点 | 设置或清除断点，不改变滚动位置；在执行该地址前暂停 |
| 编辑 → Ctrl + Enter | 载入修改后的代码 |
| 寄存器卡片 | 查看其 32/16/8 位别名 |
| 内存地址输入 | 输入地址或已定义的标签，查看对应内存 |
| 调用栈卡片 | 跳转到该次调用的入口栈地址 |
| 保存实验 | 导出 JSON；包含代码、设置、输入、断点和变量绑定，不包含执行快照或变量变化记录 |

编辑代码或输入后，需要重新载入。运行期间不逐步刷新指令、栈或寄存器，只在到达断点、结束或手动暂停时更新；每条指令仍检查断点与覆盖告警。取消固定步数暂停，可随时手动暂停长循环。首次越界、保存的帧指针 / 返回地址覆盖会暂停；点击「继续运行」后，本次执行保留告警但不再反复暂停，直到断点、结束、异常或手动暂停。回退、重置或重新载入会重新启用告警暂停。也可以单步观察。未映射访问、未支持的机器码或异常会明确停止；可以回退。

## 栈值中的函数入口

「栈与内存」将每行完整的 8 字节按小端地址解读；若与已知函数入口完全相等，在右侧显示 `函数入口 · 函数名` 和实际十六进制地址。返回地址、保存的 RBP、缓冲区等原有标注同时保留。覆盖、单步、运行停止和回退后都会重新识别；不完整或不可读的字节不会补零推测成函数指针。

函数名来自反汇编标题（如 `<do_phase> / <printf@plt>`）、ELF 的已定义函数符号、源码的 `.type name, @function` 声明、`main / _start`、直接 `call` 的具名目标，以及库函数模型。函数内部偏移、普通跳转标签和数据符号不作为入口。若源码只给了普通标签且没有其他函数信息，可以添加 `.type target, @function`。同一入口的多个已知函数别名一起显示。地址标注只说明存储值与符号匹配，不表示程序一定会调用该地址。

## 动态栈空间

执行 `sub %rax, %rsp` 后，右侧「动态栈空间」自动记录 **新 RSP（含）到旧 RSP（不含）** 的地址范围和大小。无需手动读取 RAX 或固定地址；后续 RAX、RSP 改变或进入其他函数时，已记录空间的地址不变。

1. 在分配指令后暂停，或运行至断点后从「查看空间」选择对应分配。
2. 查看完整大小和地址，按 64 字节翻页，或输入十进制 / 十六进制偏移跳转。观察不会映射或初始化内存，不可读处显示 `—`。
3. 内容变化记录列出修改步骤、指令、字节偏移和前后值。大块写入仍记录完整变化次数，每条预览最多 16 个变化字节。
4. 「查看高地址边界」定位到分配空间末端之后，方便结合普通栈视图观察邻近内存。「本页添加为变量」会把当前页的固定地址与长度加入变量监视，可继续改名、切换文本显示或保存绑定。
5. RSP 上移或所属调用返回时，按指针和调用栈推断部分 / 完全释放。回退恢复分配、释放状态和内容记录；重复分配有独立编号。已释放项显示当前内存，可能被后续空间复用，原项不会继续追加内容记录。

支持 64 位 RSP 上的 SUB / ADD、以 RSP 为基址的 LEA，以及常见立即数 AND 栈对齐造成的向下移动。PUSH / CALL 不单独算作空间分配；任意 MOV 换栈不自动猜测分配，但向上恢复 RSP 会更新已跟踪空间的释放状态。空间可以包含局部变量、对齐或临时数据，**不自动认定其中实际缓冲区的安全边界**。

保留最近 64 次分配，每块最近 100 次内容变化；快跑逐指令记录，停止时刷新。记录属于本次执行，重置或导入后从头生成；手动添加的变量绑定仍随实验保存。可用新增的「动态分配的栈空间」示例观察 96 字节空间的跨函数写入、分页与部分释放。

## 变量监视

点击「变量监视 → 添加变量」，输入自己的变量名并指定存储位置。例如：

| 变量名 | 位置类型 | 位置表达式 | 显示设置 |
| --- | --- | --- | --- |
| 计算结果 | 寄存器 | `rax` 或 `%rax` | 有符号整数；宽度自动为 8 字节 |
| 计数器 | 寄存器 | `eax` | 有符号整数；宽度自动为 4 字节 |
| 局部变量 | 内存 / 栈变量 | `-8(%rbp)` | 有符号整数；按实际变量选择 4 或 8 字节 |
| 全局变量 | 内存 / 栈变量 | 数据标签或 `0x600000` | 整数或十六进制 |
| 输入缓冲区 | 内存 / 栈变量 | `-32(%rbp)` | 原始字节或 UTF-8 文本；读取 32 字节 |

- **跟随表达式**：每一步按当前寄存器计算地址，支持 `位移(%基址,%索引,比例)`。进入其他函数后 RBP / RSP 改变时，观察的位置也会变化；地址变化同样记入记录。
- **固定到当前地址**：先运行到栈帧建立的位置，再添加变量并选择此模式。后续继续观察这块内存，避免 RBP 改变时指向别处。编辑时只改名会保留绑定；修改位置或地址方式会重新绑定。固定地址随实验保存，改变程序或初始栈地址后需重新绑定。
- 支持 1 / 2 / 4 / 8 字节整数和最多 64 字节的字节数组、文本。文本遇到首个零字节结束显示，监视范围仍是设置的读取长度。未映射、不可读或未知标签会显示原因；观察不会映射内存、生成 CPU 读事件或使程序异常。
- 点击变量名选择变化记录，查看步骤、指令地址、指令及前后值。连续运行逐指令采样，停止后更新界面；外部库函数模型作为一步记录。回退会撤销未来记录并恢复当前值。
- 最多 32 个变量，每个保留最近 200 次变化；添加时从当前状态开始，重置 / 重新载入时清空记录。修改绑定或类型重新记录，只改名保留记录。配置随草稿和实验文件保存，兼容没有变量配置的旧实验。

### 变量传入寄存器

例如将 4 字节内存 `-8(%rbp)` 命名为 `count`，执行 `movl -8(%rbp), %eax` 后，RAX 卡片出现 `EAX · count`；再执行 `movl %eax, %edi`，变量卡片会同时列出 `EAX ← count` 和 `EDI ← count`，保留真实数值。无需另外给目标寄存器添加变量。

- 按实际读写位置跟踪 `mov/movabs`、零扩展 / 符号扩展 MOV、`cltq/cwtl`、`xchg`、`push/pop`，支持经内存保存再恢复。不是按数值相同猜测，`lea` 计算地址也不会标成变量内容。
- 部分缓冲区读取显示字节范围，例如 `buf[4:8]` 表示第 4 至第 7 字节；EAX / AX / AL / AH 等只标注实际对应的范围。扩展后的值会注明扩展方式。
- 原变量位置或内容改变后，普通副本保留的不同值标注「旧副本」。支持的运算产生下述表达式；立即数覆盖、不支持的运算或其他写入会取消关联。部分覆盖会保守地取消整个重叠关联，未覆盖的独立关联保留。对普通扩展副本的部分读取不推断来源；表达式的部分读取会显式标注取位。
- 变量原值未变但寄存器关联改变时，同样生成变化记录；连续运行到断点后统一显示，回退同步恢复。重命名立即更新标签，重新绑定 / 重置清空派生关联，移除变量清除其标签。
- 每个变量最多保留最近 256 个副本位置（含内存中转），超过时丢弃最早的位置；关联属于本次运行，不导出。未列出的指令及外部函数模型不会自动传播变量名，其写入仍会清除受影响的副本。

### 运算表达式与指针解引用

若 `RAX` 来自 `x`、`RBX` 来自 `y`，执行 AT&T 指令 `addq %rax, %rbx` 后显示 **`RBX ← y + x`**。它会出现在相关变量的卡片中，寄存器区域只显示一次；实际十六进制值仍然保留。`subq %rax, %rbx` 的顺序是 `y − x`。

**y 的变量监视会直接显示「RBX 中加了 x」及 `5 → 8` 等真实前后值**，并标注发生步骤和 `y → y + x`。只有被修改值所属的变量显示这条运算说明，来源 x 仍可查看关联表达式。继续对结果运算或复制到其他寄存器后运算，仍沿被修改值的来源记录。卡片显示最近一次寄存器运算，全部记录可在下方查看；回退撤销未来记录。数值按变量选择的整数或十六进制格式及实际运算位宽显示。「监视位置的当前值」继续反映原绑定位置，寄存器运算本身不会改写原内存。

若 `x` 的值是一个地址，先 `movq x, %rax`，再 `movq (%rax), %rbx`，则显示 **`RBX ← *x`**。`movq 8(%rax), %rbx` 显示 `*(x + 8)`，带索引时可显示 `*(x + y × 8)`。之后参与加法可形成 `y + *x`。界面同时列出读取的实际地址、取出的值及读取位宽。指针变量也可以手动绑定到寄存器。

- 支持 ADD / SUB、INC / DEC、NEG / NOT、AND / OR / XOR，以及二、三操作数 IMUL。CMP / TEST 不改变关联；同一寄存器的 XOR / SUB 清零按常量处理。暂不推导移位、隐式双宽乘除法和外部函数内部的表达式，其实际写入会清除受影响的关联。
- 表达式使用指令执行时的值，**不会按变量后来的新值重新计算**。例如 `*x` 已载入寄存器后，即使目标内存改变，寄存器仍保留那次读取的值；再次载入才生成新的读取记录。「取用时」列出源变量和解引用的快照。
- 表达式按实际 8 / 16 / 32 / 64 位语义计算，结果可能截断或回绕；零扩展、符号扩展、部分取位会显式显示。未知来源的操作数使用当时的数值常量，不按相等数值猜测变量身份。LEA 不读取内存，不生成解引用。
- 支持嵌套括号、表达式复制、经内存中转、PUSH / POP、XCHG 和回退。重命名更新表达式中的名字；删除或重新绑定变量会清除依赖它的关联，并避免回退时恢复旧绑定。
- 为避免循环产生无限长文本，每个表达式最多 63 个节点、10 层，超过时折叠成 `阶段值@步骤`，继续保留实际数值与变量关联。表达式仅属于本次运行，不导出。

变量名是用户对**存储位置**的标注；不会自动识别 C 变量、作用域或栈内存复用。函数返回后，固定地址可能仍可读取，但不表示原变量仍然有效。监视地址使用绝对地址或标签，不接受 RIP 相对寻址。

## 汇编范围

v0.2.0 新增配套 ELF 装载、进程初始栈、库函数与内存映射模型、向下增长栈、进程退出码、虚拟文件及极速运行。映射、文件位置、启动阶段与退出状态均可回退。

v0.1.2 支持 `rep/repe/repz ret`（含 retq）：执行一次返回，不按 RCX 或 ZF 重复；保留 F3 前缀的编码长度。同时支持 `pause` / `rep nop` 的无状态变化教学语义，以及寄存器 / 内存形式的 `xchg`。`66 90` 的 `xchg %ax,%ax` 和 `90` 的自交换按 NOP 别名处理；普通 ModRM 编码的 32 位 XCHG 仍按寄存器写入规则零扩展。其他 REP 字符串操作与不支持的前缀组合会明确报错。

v0.1.1 修复了带后缀 NOP 的兼容性：支持 `nopl`、`nopw`、`nopq` 的寄存器 / 内存形式，以及常见填充前缀（如 `data16`、`cs`、`%cs:`）和 NOP 的 32 位地址形式。NOP 不读取或写入操作数，未映射地址也不会触发内存访问；反汇编仍按提供的机器码长度推进 RIP。

支持通用寄存器与别名（RAX/EAX/AX/AL/AH 等）、立即数、绝对内存、`disp(base,index,scale)`、RIP 相对寻址、符号标签以及标签 ± 常量。数值支持十进制、`0x` 十六进制、`0b` 二进制和前导零八进制。

| 类别 | 支持 |
| --- | --- |
| 传送 / 地址 | mov、movabs、lea、xchg、movzbl/movzbq/movzwl/movzwq、movsbl/movsbq/movswl/movswq/movslq |
| 栈 / 控制 | push、pop（16/64 位），call、ret、leave（64 位），jmp、常见 jcc、setcc |
| 算术 / 逻辑 | add、sub、cmp、test、and、or、xor、inc、dec、neg、not |
| 乘除 / 移位 | imul（1/2/3 操作数）、mul、div、idiv、shl/sal、shr、sar |
| 扩展 / 其他 | cltq、cqto、cltd、cwtl、nop、pause、hlt（教学停止） |

不支持的指令、指示和含糊的内存操作宽度会明确报错。完整 GNU 汇编器的宏、表达式、重定位与指示并未实现。.rodata 在当前教学内存中与 .data 一样可写。

### 地址与编码

源代码会生成有效的已支持指令编码，以计算真实字节长度。采用确定的编码策略，例如直接分支固定使用 rel32；**生成的地址和字节未必与 GNU as 完全相同**。符号立即数或符号位移导致编码长度改变时会报错；可改用 RIP 相对寻址或明确常量。

反汇编输入保留提供的地址与字节长度，并支持机器码续行。**原指令表仍以指令文本为准，不验证文本与机器码的语义一致性。** 装载配套 ELF 时会核对字节。转入指令表外或已改写的内存时，改为按当前字节解码执行；仅支持下述整数子集。 因此请使用可信的反汇编输出。只有图片或截取一个函数并不包含完整初始数据、库函数与被调函数；缺失的内容不会被自动猜测。

固定地址程序可在「初始状态 → 自定义寄存器和内存映射」中加入区域，例如：

```json
[{"address":"0x3ff000","size":4096,"name":"实验数据","hex":"41 42 00"}]
```

## 栈与内存约定

- 所有架构值使用 BigInt，64 位通用寄存器不会经过 JavaScript 浮点整数。
- 内存按字节存储；允许未对齐数据访问；内存区域外访问会报错。
- 模拟区域未显式写入的字节初始化为零，这不代表真实进程栈的初始值。
- 函数模式默认提供教学入口返回地址；顶层 `ret` 返回该地址时结束。可在设置中关闭。
- 栈区域在初始 RSP 上方保留 256 字节（计入区域大小），剩余区域向低地址延伸。函数模式 RSP 不强制对齐；进程模式的初始 RSP 保持 16 字节对齐，辅助向量仅包含教学子集。
- call/ret 按指令动作跟踪调用；`mov %rsp,%rbp` 被用于识别常见序言。帧标签是推断，不保证覆盖省略帧指针、手动修改 RSP 或非常规调用。
- 释放栈空间、pop、ret 不会擦除内存；修改 RSP 本身不会搬动内存。
- 内存动态解码支持 MOV、LEA、ADD / SUB / AND / OR / XOR / CMP / TEST、基本 PUSH / POP、近 CALL / JMP / 条件跳转、RET / LEAVE、NOP / PAUSE / HLT 的常用编码，包括 REX、ModR/M、SIB 与 RIP 相对地址。不是任意机器码解码器；不支持的编码、前缀或不可读取指会明确停止，不猜测或跳过。
- 动态指令按当前内存重新解码，支持可写区域内上述编码的修改和回退；指令视图展示近期执行过的动态地址及当前基本块预览，可直接设置断点。栈执行是教学约定，本版不模拟 NX。

## 缓冲区越界实验

第一版不猜测 C 变量类型与长度。使用不占指令的注释，在地址已建立后标注缓冲区：

```asm
subq $16, %rsp
# @buffer input, -16(%rbp), 16
leaq -16(%rbp), %rdi
```

标注在下一条指令执行前建立。跟踪 LEA 取得的缓冲区指针、64 位寄存器复制、立即数加减和 inc/dec，并检查相应写入。直接从缓冲区内部开始、跨过边界的写入也会告警；任意计算、经内存保存后重载的指针目前不会完整跟踪。这是可解释的教学辅助，不是完整的内存安全检测器。

示例 04 逐字节读取 `getchar` 输入，不额外写字符串终止符：

- 16 个 ASCII 字节：刚好填满缓冲区。
- 第 17 个字节：开始覆盖保存的 RBP。
- 第 25 个字节：开始覆盖返回地址。
- 默认 32 字节输入：返回地址变为 `0x3837363534333231`，`ret` 后在取指时报告未载入目标。

输入为 UTF-8 时按编码后的字节计数，中文字符不等于一个字节。HEX 模式允许明确输入 `00` 等值。缓冲区越界和递归耗尽整个栈区域是不同现象，后者会触发未映射内存异常。

## 外部函数教学模型

`getchar`、`putchar`、`puts`、`printf`、`rand`、`exit` 及启动、文件、内存函数有明确、可回退的模型。`call` 先压入返回地址，再用下一步展示模型和返回过程。模型按返回类型写入 EAX 或完整 RAX，启动模型还设置参数寄存器与栈；这些是可观察的教学约定，不表示真实 C 库保证保留其余寄存器。

- getchar 从侧栏输入取一个字节，结束时 EAX 为 `0xffffffff`。
- puts / putchar 写入程序输出。
- printf 只支持 `%d %u %x %s %c %p %%`，最多五个寄存器参数，不支持宽度、长度修饰和栈上传参。
- rand 为固定种子的教学算法，不保证与 libc 相同。
- exit 记录退出码并结束模拟，不执行系统调用。
- __libc_start_main 在模型内调度真实导入的初始化函数、main 和清理函数；GOT 在装载时预先连接至模型地址，程序中的 PLT 跳转仍会执行。
- fread 返回完整元素数，读取 stdin 或虚拟文件，支持 EOF / 部分元素；fopen 仅支持 r / rb，缺失虚拟文件返回 NULL；fclose 可回退；ferror 对正常教学流返回 0。fwrite 支持 stdout / stderr，两者合并显示。
- memset 按字节填充并返回完整指针；mmap 支持 MAP_PRIVATE | MAP_ANONYMOUS，可选 MAP_FIXED 和 MAP_GROWSDOWN。固定映射替换重叠区域并清零，向下增长按 4 KiB 页扩展，额外增长上限 1 MiB；munmap 支持这些映射的全部或部分释放。
- getpid 默认返回教学 PID 1337，可配置；srand 设置现有 rand 模型的种子。随机序列与实际 glibc 不保证相同，故动态分配大小、地址和步数也不保证与真实进程相同。

这仍是有限的教学运行环境：没有完整 Linux / 动态链接器、真实文件系统、线程、信号、errno、SIMD、浮点、段寄存器、直接系统调用或完整保护机制（ASLR、NX、栈 canary 等）。不支持的库函数、标志或 ELF 类型会明确停止；不会任意跳过函数。不能用该模拟器的结果推断真实程序在这些机制下的运行结果。

## 开发与验证

开发工具只需要 Node.js 18 或更新版本，无需 `npm install`：

```text
npm test
npm start
npm run build
```

`dist/` 是可托管的完整静态网站，可部署到 GitHub Pages 或其他静态托管。测试包含指令编码、递归、寄存器别名、标志位、RIP 寻址、除法异常、栈字节保留、缓冲区覆盖和可逆状态。界面检查记录见 `docs/VALIDATION.md`。
